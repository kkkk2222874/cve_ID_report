# Security Policy

This repository contains vulnerability research notes and proof-of-concept material for authorized security testing of owned lab devices.

## Authorized Use

The information in this repository is provided only for defensive security research, vulnerability coordination, education, and reproduction on devices that you own or are explicitly authorized to test.

Do not use the material in this repository against third-party devices, public networks, production systems, or any system where you do not have clear permission.

## Reporting or Coordination

If you are a vendor, CNA, researcher, or affected user and need to coordinate disclosure details, please open a GitHub issue in the repository or contact the repository owner through the account profile.

## Proof-of-Concept Scope

PoC snippets are intended to document protocol state transitions and vulnerability triggers. They are not intended for scanning, automation, persistence, or repeated disruption of services.

Researchers should run PoCs only in an isolated lab network and should review the target IP address, firmware version, and device ownership before execution.
